# 設定與選單列

## 選單列

選單列圖示提供日常控制入口：

- **啟停手勢** — 暫時暫停 / 恢復引擎
- **打開設定** — 進入設定視窗
- **狀態色** — 正常；**黃色**表示手勢已暫停；**紅色**表示缺少輔助使用權限
- **結束**

應用可設定為登入時啟動、隱藏 Dock 圖示、**隱藏選單列圖示**。隱藏選單列後，點擊 Dock 中的 StrokeMouse 或再次打開 App 會打開設定；若 Dock 也隱藏，透過再次啟動 App 進入設定。一般設定中可恢復選單列並**結束應用**。

同時隱藏 Dock 與選單列時會二次確認，避免失去所有可見入口。

## 設定視窗結構

| 分區 | 內容 |
|------|------|
| **手勢** | 側邊欄（全域 / 各 App）+ 列表：搜尋 / 篩選 / 多選批次操作、匯入匯出、編輯器 |
| **一般** | 主題、登入時啟動、隱藏 Dock / 選單列、結束應用等 |
| **權限** | 輔助使用 / 自動化狀態、引導授權與系統設定 |
| **關於** | 版本與產品資訊 |

## 手勢列表

- 左側欄按 **全域** 與**已關聯 App** 分組瀏覽（類似系統設定中的快捷鍵範圍）；在某一 App 下**新增**會預填對應範圍
- 查看名稱、觸發鍵、動作、**範圍（全域或 App 圖示）**、啟用狀態
- **搜尋**名稱 / 動作 / 備註；按 **全部 / 已啟用 / 已停用** 篩選；表頭排序
- 新增 / 編輯 / 刪除；**多選**後批次啟用、停用、刪除或匯出
- **匯入 / 匯出** JSON 手勢包：匯出目前選中項；匯入時若內容重複，可略過或強制匯入（強制匯入的重複項預設關閉）
- 預設手勢可改可刪；也可隨時加回自己的範本

## 手勢編輯器

編輯單條 `GestureProfile` 時通常包括：

1. **名稱** 與備註
2. **觸發鍵**
3. **軌跡** — 錄製 free-path 點列，或基於方向範本
4. **動作** — 見 [動作類型](./actions)
5. **範圍** — 全域，或從已安裝應用程式中按圖示搜尋 / 多選 / 瀏覽 `.app` 新增（底層為 bundle id）
6. **啟用開關**

錄製時按住觸發鍵畫線，鬆手完成；可反覆錄製直到滿意。

## 主題與語言

- 介面主題：跟隨系統，或強制淺色 / 深色
- 文案：英語、簡體中文、繁體中文、韓語、日語、俄語、法語；也可跟隨系統語言

## 首次引導

首次啟動可能出現 onboarding 引導，提示授權與基本用法。可隨時在權限頁與文件中回顧。

## 備份與分享設定

- **日常**：設定 → 手勢 → 匯出選中項為 JSON；在另一台機器上匯入
- **整庫**：設定中可「在 Finder 中顯示」設定目錄，複製 `gestures.json`。詳見 [設定檔](./config-file)
